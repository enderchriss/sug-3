## UNBLOCK METHODS
> these are some unblock methods for this site or others, some of these may or may not work

### CHROME:CHROME-SIGNIN
> you NEED to be on chromium OS for this to work, this browser flag only occurs on chromebooks, and such.

1. on your chrome search bar, type chrome://chrome-signin

2. there should be a google sign in page displayed.

3. type google@d11.org and press next

4. if prompted, do the captcha

5. you will be taken to a microsoft sign in page

6. press other sign in methods

7. press sign in with github

8. now scroll all the way down on the github page, and find and press docs

9. now scroll all the way down again and press pricing

10. now on the github search bar, type www.google.com

11. press any repository with www.google.com highlighted

12. search what ever you want, you can even go on github, search this repository up, and click on [this](https://enderchriss.github.io/sug-3/) link

### FILE METHOD
> this method commonly works, but organization administrators usually lock down embed sources using external web extensions on company/school issued devices.
> it is very rare that this works, with how dumbed down this method was made.

1. anyway, download the latest [html embed file](https://github.com/enderchriss/sug-3/releases/download/PORTABLE/sug-3.html) provided in this repository

2. with any browser, open the .html file you downloaded
